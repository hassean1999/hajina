# live_app (Flutter skeleton)

Original, from-scratch skeleton for a live social app: auth, profile, home,
live rooms, chat, gifts, wallet, levels, notifications, settings.
All data is mock data in each feature's `data/` folder; replace with a real
backend (and a licensed live-streaming SDK) feature by feature.

Run: `flutter create . --platforms=android,ios && flutter pub get && flutter run`
