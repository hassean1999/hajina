حجينه - مشروع أندرويد
1) سوّي حساب مجاني بـ github.com وبعدين New repository (سميه hajina).
2) Add file > Upload files وارفع كل محتويات هذا المجلد (مو المجلد نفسه)، بضمنها مجلد .github
3) روح لتبويب Actions، راح يشتغل "Build APK" لوحده (5 دقايق تقريباً).
4) من يخلص اضغط عليه، وجوه Artifacts نزّل Hajina-APK وفيه Hajina.apk
أو افتح المشروع بـ Android Studio واضغط Build > Build APK.
